# 論文もどき

日常の小さな疑問を、仮説・観察・結論の形でまとめる投稿サイトの試作です。

## 公開サイト

https://peterpeterpeter333.github.io/bonbon/

GitHub Pages は `main` ブランチのルートから公開します。`index.html` を更新して `main` に反映すると、サイトも自動で更新されます。

## 試す方法

公開サイト、または `index.html` をブラウザで開いてください。サンプル論文を読む、カテゴリーを切り替える、自分の論文を作って下書きとして保存する操作を試せます。タイトルだけで保存でき、本文には見出し付きの文章と画像を好きな順に挿入できます。

## 現在の範囲

- 投稿データと画像はブラウザの `localStorage` に保存され、この端末だけで表示されます。画像は保存前に縮小され、1つの論文につき3枚までです。ブラウザの保存容量を超えると保存できません。\n- 必須入力は論文タイトルのみです。文章は1まとまり500字までで、100字前後を読みやすさの目安にしています。
- サンプル論文は架空の内容です。
- アカウント、ほかの利用者への公開、通報・審査、広告配信はまだありません。

実際の投稿サービスにするには、共有データベース、認証、投稿の管理と通報対応などを追加します。
