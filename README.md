# bonbon / 論文もどき

日常の小さな疑問を、自由な見出し・文章・画像で「論文もどき」にするサイトです。

## 公開サイト

https://peterpeterpeter333.github.io/bonbon/

GitHub Pages は `main` のルートから公開しています。共有投稿は Supabase に保存し、下書きは各端末の `localStorage` に保存します。

## 現在できること

- タイトルだけで下書きを保存・編集・削除。見出しと文章は任意。文章は1ブロック500字まで。
- 本文中に画像を最大3枚挿入。保存前に縮小します。
- カテゴリー別に閲覧。共有投稿が有効なときは実際の投稿を表示します。
- メールリンクでのログイン、共有投稿、公開画像、投稿者による削除、ログインした利用者からの通報。

## 共有投稿の設定

1. Supabase でプロジェクトを作成します。
2. Supabase の SQL Editor で [`supabase/setup.sql`](supabase/setup.sql) を実行します。公開投稿テーブル、通報テーブル、画像バケット、アクセス制御を作ります。
3. Authentication → URL Configuration で Site URL と Redirect URL に `https://peterpeterpeter333.github.io/bonbon/` を設定します。
4. `config.js` にプロジェクト URL と **publishable key** を入れて `main` に反映します。これはブラウザ向けのキーです。`service_role` や secret key は入れないでください。
5. 公開サイトでメールリンクのログイン、2台の端末からの投稿閲覧、画像投稿、投稿削除、通報を確認します。

Supabase プロジェクト `bonbon` で初回 SQL を実行済みです。メールリンクからの本人ログインと、ログイン後の投稿・削除・通報は運営者アカウントで確認してください。

## 安全な運用の最低限

- データベースには RLS を設定し、誰でも閲覧、ログインした本人だけが投稿・削除できるようにしています。
- 画像バケットは公開用です。投稿に使った画像は URL を知る人が見られます。
- 24時間あたり10投稿の簡易制限があります。大規模運用には追加の迷惑投稿対策が必要です。
- 通報は `paper_reports` テーブルに蓄積されます。運営者が Supabase Dashboard で確認して対応する必要があります。
- 一般公開を拡大する前に、利用規約・プライバシー説明・通報対応手順・管理画面を用意します。

## 今後の順番

共有投稿の動作確認 → プロフィール → いいね・返信 → フォローとタイムライン → 検索・通知。各段階で通報と管理機能も強化します。
